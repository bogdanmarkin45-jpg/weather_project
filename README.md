# Weather Diary

**Автор:** Богдан Маркин
**Описание:** Консольное приложение для ведения дневника погоды с визуализацией данных.

### Как запустить
1. Установите зависимости: `pip install matplotlib`
2. Запустите скрипт: `python main.py`

### Функции
- Сохранение данных в JSON.
- Валидация ввода дат и чисел.
- Построение графиков температуры через Matplotlib.
